# Информационная система для коллекции видеоигр

Система для управления личной коллекцией видеоигр с функциями статистики и рекомендаций.

## Функционал

- ✅ Регистрация и авторизация пользователей
- ✅ Личный кабинет с библиотекой игр
- ✅ Справочник игр
- ✅ Добавление игр в коллекцию
- ✅ Подсчет статистики (жанры, количество часов)
- ✅ Рекомендации на основе статистики

## Технологии

- **База данных:** Supabase (PostgreSQL)
- **Фронтенд:** HTML, CSS, JavaScript
- **Хостинг:** GitHub Pages

## Быстрый старт

### 1. Настройка Supabase

1. Откройте [Supabase Dashboard](https://supabase.com/dashboard)
2. Перейдите в **SQL Editor**
3. Выполните SQL скрипт из файла `supabase_schema.sql`

### 2. Локальный запуск

```bash
# Простой HTTP сервер (Python)
python -m http.server 8000

# Или используйте любой другой статический сервер
```

Откройте `http://localhost:8000` в браузере.

### 3. Деплой на GitHub Pages

См. подробную инструкцию в файле `GITHUB_PAGES_DEPLOY.md`

## Использование

1. **Регистрация:** Создайте новый аккаунт
2. **Вход:** Войдите в систему
3. **Справочник игр:** Просмотрите доступные игры и добавьте их в коллекцию
4. **Моя коллекция:** Управляйте своими играми, указывайте количество наигранных часов
5. **Статистика:** Просматривайте статистику по жанрам и общее количество часов
6. **Рекомендации:** Получайте персональные рекомендации на основе вашей коллекции

## Настройка

### Credentials

В файле `static/js/app.js` указаны:
- `SUPABASE_URL` - URL вашего проекта Supabase
- `SUPABASE_KEY` - API ключ (anon key)

### Безопасность

- Используется Row Level Security (RLS) в Supabase
- Пароли хешируются на клиенте (SHA-256)
- API ключ виден в коде (это нормально для anon key)

## Решение проблем

### Ошибка соединения

1. Проверьте, что таблицы созданы в Supabase
2. Проверьте правильность API ключа
3. Откройте консоль браузера (F12) для просмотра ошибок

### Таблицы не созданы

Выполните SQL скрипт из `supabase_schema.sql` в Supabase SQL Editor.
